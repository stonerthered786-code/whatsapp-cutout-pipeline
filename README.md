# WhatsApp → Cutout Pro Pipeline

Fastest way to process WhatsApp images using Cutout Pro.

## 🚀 Features

* One-click image extraction from WhatsApp Web
* Automatically copies image to clipboard
* Opens Cutout Pro in a single reusable tab
* Optimized workflow for background removal & enhancement

## ⚡ Workflow

1. Hover image in WhatsApp Web
2. Click the icon
3. Go to Cutout tab
4. Press Ctrl + V

## 🧠 Why this tool?

Instead of:

* Right click → Copy → Switch tab → Paste

You get:

* Click → Paste → Done

## 📦 Installation

1. Install Tampermonkey
2. Create new script
3. Paste `script.user.js`
4. Save

## 🔒 Notes

* Clipboard access requires user interaction
* Full auto-paste is restricted by browser security
